-Aquí vemos el sistema de arrancada es: Windows 11
-A quin disc o partició està instal·lat: En la partición C
-Quant temps espera abans d'arrencar: 30 segundos
-Quin fitxer inicia Windows: El fichero es winload.efi
-Qui decideix l'arrencada (Boot Manager): El Administrador de arranque de Windows ({bootmgr}) es el encargado de gestionar el menú de inicio y decidir qué sistema operativo se debe cargar según la configuración del BCD.
-Qui carrega el sistema (Boot Loader): El Cargador de arranque de Windows ({current}), a través del archivo winload.efi, es el responsable de cargar el núcleo (kernel) del sistema operativo y los controladores críticos en la memoria para que Windows 11 pueda iniciarse.
